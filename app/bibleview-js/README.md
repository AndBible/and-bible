# bibleview-js

Vue 3 + TypeScript frontend used by AndBible WebView.

## Setup

```bash
npm ci
```

## Development

```bash
npm run dev
```

## Validation

```bash
npm run test:ci
npm run lint
npm run type-check
```

## Build

```bash
npm run build-debug
npm run build-production
```

## Preview production build locally

```bash
npm run preview
```

For full project contribution workflow, see `../../CONTRIBUTING.md`.
