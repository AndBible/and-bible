# AndBible Changelog

## New Features

- Add per-workspace label display mode override (7ec5c849b)
- Add scroll-to-top button next to section titles (01b8ac103)
- Add "Italicize added words" setting for Strong's modules (c7053843b)
- Add tab view with responsive layout for multiple Strong's/morphology dictionaries (c159b9d45, 989b7bee2)

## Improvements

- Improve backup view with cleaner UI, auto-backup restore, and database reset (d00534fad)
- Enhance monochrome toolbar and window button styling (bf8aa0782, fd42e4ed5, a3852a4ac)
- Store window button bar visibility per workspace (ab5e718d3)
- Show both Strong's and morphology data when clicking links (4572f841f, f16a12ed3)
- Improve translation note styling in dictionary (b04446ee1, c3129bde8)
- Use inherited colors for Strong's/morphology labels in monochrome mode (88f4b7524)
- Improve dictionary title scroll button positioning and touch target (2ef335d88)
