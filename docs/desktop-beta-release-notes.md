# AndBible Desktop beta

This is a beta of AndBible for the desktop. It is the same offline Bible study app as on Android, with the
same Bible text view, bookmarks, notes, StudyPads, search and workspaces.

## What works

- Installing Bibles and other modules from the catalogue, or from a module zip file.
- Reading, scrolling, the chapter chooser and `Ctrl+L` for going to a reference.
- Selecting text: copy, bookmark (with labels) and notes.
- StudyPads.
- Search, including building the search index.
- Several windows with synchronised scrolling, and switching workspaces.
- Synchronising with a Nextcloud server (WebDAV), also with the Android app. Google Drive sync is not available on desktop.
- Backup export and import; opening a backup file from the file manager restores it.
- Night mode and the text options.
- Finnish and Hebrew (right-to-left) interface, among the other languages of the app.
- Closing and reopening the app keeps your position, windows and settings.

## Known limitations

Printing, find in page, desktop notifications and text to speech are not there yet, and the app does not
follow the dark mode of the operating system. Wayland-native sessions, IME input, fractional scaling and
touchpads have not been tested. Full list: <https://andbible.org/docs/desktop-beta/>
