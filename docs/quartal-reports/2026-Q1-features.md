# AndBible Q1 2026 — New Features & Improvements

Period: January 1 – March 31, 2026 (builds 5.0.903 – 5.0.1065)

---

## 1. AI / LLM Integration (Major Feature)

The largest new feature of Q1: a full AI assistant system built into AndBible, enabling users to interact with Bible content through LLM-powered tools.

### 1.1 Core Infrastructure
- LLM agent infrastructure with tool calling support (agentic loop)
- Multi-provider backend: **Anthropic (Claude)**, **OpenRouter**, **xAI (Grok)**, + many others, also custom OpenAI-compatible endpoints (including self-hosted)
- Provider tier system (recommended, supported, community)
- Dynamic model list fetching from providers (OpenRouter, OpenAI-compatible)
- API cost tracking and usage display (per-call and session totals)
- Prompt caching support (Anthropic native, xAI via x-grok-conv-id header, OpenRouter breakpoints)
- Foreground service for background AI execution (continues when app is backgrounded)
- AI disclaimer warning and acceptance gate

### 1.2 LLM Tools (Agent Capabilities)
- **Bible tools**: Search Bible (Lucene with pagination), get commentary (verse ranges, deduplication, response size limit), Strong's number search
- **Bookmark tools**: Create bookmark (with label, sub-verse offsets), delete bookmarks, labels, and associations
- **Study Pad tools**: Create study pad, get study pad content (info/index/page modes), finish with study pad
- **My Documents tools**: 6 CRUD tools for creating, editing, listing, reading, deleting pages + finishWithMyDocumentPage
- **Window management tools**: 4 tools for controlling windows
- **Output tools**: finishWithDocument (title/content separation), finishWithoutDocument (action-only), taskComplete flag
- Per-prompt tool enable/disable with allowlist-based restrictions
- Global default tool permissions for all tool types
- Category-based grouping in tool permission screens
- Tool Info view and help button in prompt editor

### 1.3 AI Document System
- AI documents (LLM-generated pages) saved with caching system
- AI document regeneration (with custom prompt, additional instructions, "fresh run", keep previous)
- AI document page markers shown in Bible view (whole-page bookmarks on commentary pages)
- "Generated by" footer on AI documents
- AI document access filter settings
- Delete/regenerate action links on documents

### 1.4 Prompt System & Editor
- Built-in read-only prompts (thematic Bible study, summary, commentary, enhance note, custom prompt, explain verses → study pad)
- Edit Prompt activity with TabLayout (behavior settings in Advanced tab)
- Per-prompt model selection
- "Edit before run" / "Specify before run" option
- "Ask model before run" global setting
- Auto-include options for installed documents and commentaries
- Workspace-scoped AI prompts with window context
- CSV import/export for AI prompts
- Text transformation mode for prompts (bibleOnly filter, noDocumentCreation toggle)
- Hide/restore/reorder UI for prompts
- Placeholder for empty documents with edit prompt link

### 1.5 Agent Log & Debugging
- Agent log widget (expandable panel, session cost display, model name, auto-scroll)
- Raw LLM log viewer, JSON pretty-print, tool definitions
- LLM comments shown in agent log
- Default model selector in agent log widget
- Raw log link shown on AI execution error and cancellation

### 1.6 AI Settings & Sync
- Dedicated AI connection settings activity with provider selection
- Commentary filter dialog with select all/none, remembered deselections (synced globally)
- Settings hint in commentary filter dialog
- AI Settings hidden behind experimental flag (progressively revealed)

### 1.7 AI Integration Points
- AI action in bible verse action modal (with highlighted text context)
- AI action in text selection context menu (with highlighted text context)
- AI button in window button menu (whole page context)
- AI button in workspace button menu (workspace's windows as context)
- AI button in note editors for LLM-assisted note enhancement
- Built-in AI label automatically added to LLM-created bookmarks
- Model selection dialog when starting AI action from window button or regenerating

A comprehensive system for tracking Bible reading and memorization progress.

### 2.1 Reading Progress
- Automatic reading tracking (auto-track setting, per-window)

- Reading cycle switching and per-cycle filtering
- Reading Progress settings activity (syncable Room database)

- Option to hide progress bars in book chooser (#3710)
- Filter intros and apocrypha from reading progress view
- Separate reading and memorization progress in reference picker

### 2.2 Memorization System
- Memorization tracking: targets, manual marking, progress view, Bible indicators
- **Word Scramble** mode with drag & drop
- **Word Order** mode with drag & drop
- **Word Blur** mode with reveal controls
- **"Type It"** mode for typing-based memorization
- **Listen in Loop** feature in memorization menu
- Optional verse reference memorization
- Goal+/Goal- toggle, set-difference target removal
- Memory tab with pagination, timestamps, Bible overview heatmap
- Memorization indicators reactive to all config changes (CSS overlay lines)
