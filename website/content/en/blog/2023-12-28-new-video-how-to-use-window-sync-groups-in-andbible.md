AndBible has had syncable windows (by windows we refer to bible/text panes) almost from the beginning of app, as far as I know correctly. Traditionally until 4.0 it has been possible to either have window synced or non-synced.

Now in 5.0 (released in November 2023), I introduced a feature that allows a set windows to be synced together, and other set of windows be synced separately. In this video I'm showing you how to use window sync groups to make it happen.
