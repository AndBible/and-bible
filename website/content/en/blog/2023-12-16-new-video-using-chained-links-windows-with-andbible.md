In AndBible, we use links window as a concept to tap conveniently links and to display simultaneously the parent text as well as the link target text. Link target text is shown in so called *links window*.

In AndBible 5.0 this concept was further developed. Now you can also open links from links window, in another links window, in a chained manner. In this video I'll explain and show this behavior in action.
