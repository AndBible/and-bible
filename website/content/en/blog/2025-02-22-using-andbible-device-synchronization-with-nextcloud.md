Device synchronizing feature using Google Drive has been implemented in AndBible for a while now. Now AndBible offers alternative to use NextCloud backend instead. This option is also available on F-droid devices, that have not been able to use Device synchronization at all so far.

In this video I will explain how you can enable device synchronization in your devices using NextCloud backend.

AndBible is completely free open source Bible Study app. You can support AndBible development by sponsoring some development time: <https://shop.andbible.org/>
