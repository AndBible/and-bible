When using Device Synchronization to keep multiple devices in sync, AndBible uses some space in Google Drive. That space allocation is incrementally increased as time goes by. That is because every time AndBible uploads a small "patch file" containing new changes to its internal database. Those files are never cleaned up automatically (as of now), but user can rather easily "clean up" it manually, when needed.

In this video I'm showing how by resetting reset device sync you can save some space in Google Drive.
