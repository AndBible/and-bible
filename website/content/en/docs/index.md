# Welcome to the AndBible: Bible Study’s documentation! {#welcome-to-the-andbible-bible-study-s-documentation}

The **Bible Study App** is a free, opensource application provided by AndBible that gives users an advanced
and flexible interface for studying the Bible.

- [Github Repository](https://github.com/AndBible/and-bible)
- [Webpage](https://andbible.github.io/)
- [Frequently Asked Questions](faq.md)

!!! note

    This project is under active development.
